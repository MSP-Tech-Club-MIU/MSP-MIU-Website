# Admin: Events and attendance

**Paths:** `/admin/events` · attendance view via `/admin/events?view=attendance` (alias `/admin/attendance`)

## Events

1. Open **Events**.
2. Create or edit an event (title, dates, description, media/thumbnail as supported).
3. Publish changes — the public `/events` and home feed pick them up (season-scoped).
4. Review or remove event feedback from the admin feedback tools when needed.

Public users can also submit feedback on event detail pages.

## Attendance

1. Switch to the attendance view on the Events tab (or open the attendance alias).
2. Review pending attendance requests submitted from `/attendance-request`.
3. Approve, reject, or update status as needed.
4. Export CSV when you need offline processing (also available via attendance APIs for board/admin or department 6).

## Tips

- Keep event season assignment correct so past seasons stay historically accurate.
- Attendance reviewers in department 6 can use dedicated attendance APIs even without full admin UI.
